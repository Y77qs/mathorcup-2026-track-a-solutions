# A题改进建模方案：少量候选、明确取舍

本文件是待实施、待比较的模型规范，不是已经训练验证的最终方案。原题及数据事实以已有 `problem_brief.md` 为依据；缺少的标签锚点、阈值、派生列公式仍然缺少。本轮不写正式论文正文。

## 先用直观语言理解三个模型

- **Q1 是预测。** 输入一杯酒的化学测量，预测它在果香、麦芽味等维度上的强弱。低秩模型相当于先找少数几条共同的变化方向，再组合成 50 项感官预测；图惩罚提醒模型：经常一起变化的化合物，系数不宜无理由地完全相反。二者都是可被数据推翻的假设。
- **Q2 是解释关联。** 如果某成分在果香较强的酒里常较高，它是线索；若这种关系只来自“某类酒同时果香高、成分高”，换到同一风格内部可能消失。两种关系都值得看，但含义不同。经常一起变化的成分可能轮流进入前三，不能因此认定某一个是唯一关键原因。
- **Q3 是生成和设计。** 条件生成要学到一种风格中不同成分的分布与搭配；迁移要在少改原谱、接近目标风格、控制缺陷之间取舍。把果香代理模型调高，只说明模型预测变高，实际风味仍需要品评验证。

## 2. Q1：保留图低秩思路，改成精确求解

### 2.1 模型和解

训练内补值、变换之后得到设计矩阵 Z（化学特征及缺失标志），目标为 Y。先再次中心化：Zc=Z−平均Z、Yc=Y−平均Y。即使先做了 RankGauss 或截断 z-score，也必须做这一步。考虑：

\[
\min_{\operatorname{rank}(B)\le r}\quad
\frac1n\|Y_c-Z_cB\|_F^2+\lambda\|B\|_F^2+
\gamma\operatorname{tr}(B^TLB),\qquad\lambda>0,\gamma\ge0.
\]

L 使用带符号图的 `diag(sum(abs(W)))−W`，缺失标志对应零图块。它的二次型为各边的非负加权平方差，所以只要 W 对称，L 即为半正定；不要求原相关矩阵本身半正定。不要为绘图阈值先任意改变所有相关系数。图的符号约束仍是统计先验，需 γ=0 消融验证。

令 A=ZcᵀZc/n+λI+γL，C=ZcᵀYc/n。A 正定。取 CᵀA⁻¹C 的前 r 个特征向量组成 Vr，则一个全局最优解为：

\[
B_r=A^{-1}CV_rV_r^T,\qquad b=\bar Y-\bar ZB_r.
\]

实现用 Cholesky 求线性方程，避免显式求逆。解释这条式子的关键是：令 U=A^(1/2)B，目标变为常数加 `||U−A^(−1/2)C||²`，且可逆变换保持秩；截断 SVD 就给出最优低秩近似。若截断处特征值并列，子空间/系数可能不唯一，但最优目标值一致。

低秩 Ridge 的相关方法见 [Mukherjee 与 Zhu 原论文](https://dept.stat.lsa.umich.edu/~jizhu/pubs/Mukherjee-SADM11.pdf)；上述固定图惩罚的推广是本轮配方推导。它不是新的原创算法声明。本轮 23×8→5 的合成小例中，两种等价分解最大差 `2.78e-16`，达到解析下界，秩为 2。**这只证明小例实现与公式一致，不是比赛误差改善证据。**

### 2.2 只比较必要的候选

| 候选 | 用途 | 去留条件 |
|---|---|---|
| 训练中位数 | 最简单误差下限参照 | 始终报告 |
| 普通 Ridge：r=50、γ=0 | 检验图和低秩是否真的有增益 | 如复杂方法增益不稳定，则回退它 |
| 图 Ridge：r=50、γ>0 | 隔离图的贡献 | 与相同预处理/截距/λ的无图项做消融 |
| 精确图低秩：r∈{3,6,10} | 首选待验证方案，延续原主线 | 只根据嵌套内部验证的实际收益决定 |
| 加一个固定参数 HGB 的融合 | 保留原非线性补充 | 第一轮线性比较通过后再跑；收益不足即不用融合 |

初始网格冻结为表示 `{截断zscore, RankGauss}`、λ `{0.1,1,10}`、γ `{0,0.1,1}`、r `{3,6,10,50}`。这 72 个组合覆盖上述线性对照；每个 `(表示,λ,γ)` 的线性方程/分解可复用四个秩。真实训练中的误差不一定比原 ALS 更好：训练目标最优与泛化最优是两回事。

融合的权重改为直接求 `min mean(|y−Σw_k p_k|)`，约束 w≥0、Σw=1（可转成线性规划）。以训练内 OOF 作为拟合元模型的材料；拟合这些权重用过的误差只称训练选择量。全流程在外层训练内完成，最终只在外层留出评分。先用一组全局权重，按 A/F 30 项拟合，再同时报告 50 项；不在 250 行小样本上为每一项寻找一套权重。

0–6 输出继续采用显式相对等级：训练经验分布 F_j 给出 `g=clip(floor(6 F_j(ŷ)+0.5),0,6)`。保存连续预测、相对等级和映射参数。外折真实连续标签也用同一训练 F_j 映射，只能评价“推断相对等级的一致性”，不能称人工评分准确率。完整 250 行提供可追踪的 OOF 结果（每次重复单列）；全量重拟合给新样本使用的最终模型，二者分开保存。

## 3. Q2：修复对齐，增加风格与替代关系的证据

### 3.1 第一轮先保留修复后的旧榜

现有三方法共识和 bootstrap 可作为复现基线。修复行列对齐、候选类别和输出名称；逐条说明榜单是相关/预测关联，不能称因果因素。总相关、风格调整后的相关及预测系数回答不同问题，不把均值分数解释成有统一因果含义的量。

化学合理性核查依据附件名称、阈值、单位和可核验的原始研究逐条建立证据；不能因为模型把某成分排到前三，再编出对应风味机制。Protein、Iron 等放在扩展指标表，严格化合物表的候选需由字典明确界定。

### 3.2 新候选采用两条独立的图 Ridge 轨道

总体轨道 T 中 H 仅为截距列；风格调整轨道 W 中 H 为风格虚拟变量。分别拟合：

\[
\min_{\Theta,B}\ \frac1n\|Y-H\Theta-ZB\|_F^2
+\lambda\|B\|_F^2+\gamma\operatorname{tr}(B^TLB).
\]

截距不惩罚，可将 Z、Y 都投影到 H 的残差空间后求图 Ridge。标准化在训练内完成；先不增加稀疏或低秩惩罚，便于复用 Q1 求解器且减少调参。T 的图来自训练总体 Spearman，W 的图来自风格残差化后的化学秩相关，分别记录；不要让一条轨道的估计对象悄悄替换另一条。按每维标准化系数绝对值给候选，重采样频率作为稳定性排序，平局依次按点估计强度、固定特征名排序。

**预先裁决：T 提供候选正式 Top-3，W 提供风格依赖诊断，不把两轨分数平均。** 题目未要求控制风格后的直接效应，T 应称“总体预测关联因素”。W 问的是“在风格差异之外，还有哪些成分能解释该维变化”。解释被风格调整消除或符号反转的关系；调整可能移除本来有意义的风格差异，不能因此宣布 T 错误。没有因果标签，不能用某个 Jaccard 值证明新榜更真实。

网络要进入实际回归惩罚；用 γ=0 与 γ>0 对照，同时给图网络。训练预测评价中图由训练行重建；最终描述性全样本分析明确使用附件 2。网络本身记录边阈值、正负号、孤立点和节点映射。

### 3.3 不把“同一组里换人”误判为完全没有线索

每个感官维度的输出包括：严格 Top-3、候选前 10、总/调整相关及其符号、系数符号、入选频率 π、风格内符号一致性、化学类别和证据来源。

模块作为补充：在明确的参考图上用 `1−|rho|` 完全连接层次聚类、距离阈值 0.5，构成组内相关较紧的参考模块；不沿相关链把大半个网络都算作一个模块。单节点也可成模块。报告“该固定模块中至少一个成分入选”的频率，以及模块内替代名单，不强行规定前三来自三个不同模块。

参考模块用于结果汇总，不把它悄悄固定成重采样模型的先验。每次 bootstrap 重做补值、尺度、训练图和回归；若另报告模块本身稳定性，应重新聚类，再按成员重叠匹配，不能拿固定模块入选率代替聚类稳定率。

先跑 100 次诊断，正式结果至少 500 次。冻结调参后 bootstrap 给的是“给定参数的稳定性”；再做较少次数（如 100 次）重新调参敏感性，明确二者不同。π 的蒙特卡洛误差最大约 `sqrt(.25/500)=.0224`，它不是“该化合物正确的概率”。γ=0 消融如果更稳且误差相当，应降低图在关键因素结论中的作用，而不是为保留模型名字隐藏结果。

图 Elastic Net、模块稀疏回归只作第二顺位备选：只有 Ridge 系数分散且重采样不足以解释时才考虑，第一轮不增加这条开发线。

## 4. Q3：保留小样本生成，把约束完整写进求解

### 4.1 生成：收缩 Copula 仍是首选候选

用经验边际描述每种化合物的取值，再用相关结构描述它们如何搭配。样本少的风格向全局共享结构收缩，例如 `F_sj=w_sj F_local,sj+(1−w_sj)F_global,j`，`w_sj=n_valid,sj/(n_valid,sj+κ)`；各列使用实际有效观测数，相关矩阵也进行正定收缩。这能表达“只有三款酒的风格，不足以单独学高维关联”。

**派生列的具体取舍：** FIX 层保留旧 231 列统计谱用于定位修复影响，并标注派生恒等式未验证；推荐 CAND 层只对 226 个非派生字段生成/优化。五个汇总字段用训练折拟合的独立重建层补充，并给外折重建误差与状态。QP 约束用的线性感官代理也只输入这 226 列，避免优化器仅修改“总酯”等汇总数来骗过代理。若重建不可靠，不能硬称已得到完整物理一致的 231 列；所有候选的主质量比较固定在共同 226 列，231 列结果作为补充。该改变是待验证候选，不能混进“只修 bug”的收益。

比较三个层次：同风格训练行重采样（复制参照）、收缩独立边际（无相关结构）、修复后的收缩 Gaussian Copula。若 Copula 没有改善联合分布质量，就回退独立边际并披露依赖结构不足。不优先开发 GAN/扩散模型；目前没有额外数据支持它们增加的估计自由度。

边际用本训练部分的实际可用值及明确标记的报告零/地板类别拟合，不把中位数插补产生的大量相同值悄悄当成真实观测。为了估计相关结构如必须补值，单独记录规则，并做缺失/地板处理敏感性。高地板列输出其类别概率；未经确认不称精确检出率。

先保存条件生成谱，再生成需要低缺陷的设计版本。已知可逆变换与约束固定后，在标准化存储坐标 z 上做：

\[
\min_z \frac12\|z-z_{raw}\|_2^2\quad\text{s.t.}\quad l\le z\le u,\quad Az\le b.
\]

这一次性处理声明的范围与线性代理上界，替代“先压一个缺陷、再沿代理方向移动、却破坏其他列”的循环。严格凸目标在非空可行域上有唯一投影；它保证的是已声明数学约束，不是已经满足全部酿造机理。投影会改变分布，必须报告移动距离、贴边比例、相关变化、拒绝/不可行率，并重新计算画像与指标。

### 4.2 迁移：源样本保留与目标参考之间的凸取舍

源谱是 z_i。目标参考 z_ref,i 可来自训练内的目标风格边际分位映射；如果目标/源边际不足，采用一个训练内目标样本匹配参照。参考计算规则固定，评估行不得参与学习边际。目标均值作为最简单对照，但不把把所有酒拉到中心作为唯一成功标准。

推荐候选：

\[
\min_{z,t}\ (z-z_{ref,i})^TQ_t(z-z_{ref,i})
+\lambda\|z-z_i\|_2^2+\eta\sum_j t_j
\]
\[
 -t\le z-z_i\le t,\quad t\ge0,\quad l_i\le z\le u_i,\quad A_i z\le b_i.
\]

其中 λ>0、η≥0；Q_t 是目标风格协方差的正定收缩逆，固定在训练数据上，低样本时退到对角矩阵。目标/参数随训练确定后，这是凸 QP；L1 指**标准化存储坐标改变量**，不是实际添加克数，也不是化学反应成本。η 只控制改动倾向，不保证只有少数列改变。

初始取 λ `{0.1,1,10}`、η `{0,0.05}` 作小型 Pareto 对照，不寻找一个虚构“最优口感”标量。先控制缺陷可行，再比较目标接近程度、源谱改动和多样性。目标参考项的距离和独立于优化目标的完整谱分布诊断同时报告。

### 4.3 约束必须逐类定义

- 线性校准浓度有非负下界；log10 列的正浓度上界 c≤u 等价于存储值≤log10(u)。未知单位列只限制明确声明的存储支持范围，不生成其 OAV。
- 经验训练范围属于“避免外推”的设计限制，不是物理定律。迁移时源样本在范围外：保存原值和 OOD 标志，可以预先规定逐样本支持范围包含源点；不能先截断源值，再把截断值当原酒作“不恶化”比较。硬物理边界不能因此放宽。
- DMS、Diacetyl、4VG 主迁移约束采用 `c'_j≤c_source,j`（对可核验源值）；另报超阈值程度。这样源谱本身在已知部分可行。可再做更严格设计 `c'_j≤min(c_source,j,T_j)`，但它比题目的不恶化更强，可能与其他约束冲突，不能混作一个成功率。
- `X.E..2.nonenal` 加真实浓度不增。没有阈值时不填造 T；同列同尺度比较不需要虚构阈值。感官 t2n 代理另外报告。
- Stale hops 只能用训练拟合的线性代理 `aᵀz+b≤预测源值` 作设计约束。可另以训练 bootstrap 的一组线性模型全部约束作为保守敏感性，但它不保证真实风味不恶化。不得把任意 `.05 sd` 松弛悄悄称作严格不增。
- 地板/报告零分支：对数零不能写成 `log10(0)`，也不能用 −300 伪造物理零。将相应报告状态冻结或单独分类处理，说明只保证报告尺度不增；如源状态无法确定，逐项标“真实浓度约束不可证”。
- **派生列特别处理：** kcalperc、acids_sum、esters_sum、aroma_hops_sum、sulfur_sum 来源于其他量。拿到原公式时应重算，不能让它们独立漂移。未提供公式时使用前述统计重建候选，不可捏造加和公式；全 231 维输出只可称统计谱，标出派生一致性未验证。预测重建是补全，不是恒等式证明。公式若使目标/约束变非线性，需单独建立求解器，不能继续无条件宣称整个问题是凸 QP。

由于训练中存在零/缺测源行，最终约束表应有 `verified / conditional / not_identifiable / infeasible`，不能只有一个 pass 布尔值。严格低缺陷版本无解时保留不可行证据；回退到源谱只可称“不实施迁移”，不能算迁移成功。

### 4.4 画像与科学边界

画像模型先在真实外折酒上验证，再对生成谱预测。用于优化的线性代理和作为敏感性对照的 Q1 预测器都只接触训练资料。二者在新谱上同意，只能增加模型一致性证据；它们训练于同源数据，不能替代独立品评。

未见风格只有名字时，使用全局回退并标明未知。实际迁移尚无成对真实“迁移后”标签，因此目标距离、多样性、近邻距离和代理不增都只是设计诊断，不能成为真实迁移准确率。

QP 可使用 [OSQP 官方支持的约束形式与残差/不可行证书](https://osqp.org/docs/solver/)。记录解的原始/对偶残差、物理单位复验、目标值和求解状态；`solved inaccurate` 不能自动当完全通过，小例另用不同求解方式交叉验证。
