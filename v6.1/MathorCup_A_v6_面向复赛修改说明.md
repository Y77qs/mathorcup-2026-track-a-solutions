## 2. 第三问：四项实现修正

### 2.1 修正 stale 代理半空间的截距

位置：`src/q3_transfer_fix.py:491–497`；代理定义见 `src/q3_lib.py:365–378`。

代理为 `f(z)=aᵀz+c`，要求 `f(z_new) ≤ f(z_source)+tol`，应统一写为：

```text
aᵀz_new ≤ b
b = f(z_source) - c + tol
  = aᵀz_source + tol
```

当前左侧只有系数项，右侧却保留完整源预测，漏扣了 c。九折 c 均为负，因此旧解是在更严格的域里求得；已有 198 个 QP 保存结果的 stale 代理确实不增，不应将本问题误说成旧解已违反不增要求。

修改要求：

- 构造、可行性预检、投影、QP、问题哈希、残差和证书使用同一个修正后的 b。
- 保留化学 DMS、双乙酰、4VG、真实 trans-2-nonenal 的既有上界及各列尺度规则。
- 增加一个有非零截距的小例，直接比较完整预测差与半空间残差；正、负截距都覆盖。
- 重跑原协议下两个 QP 策略的全部 198 次求解，并同步表图。这是 11 个源样本在 9 个训练上下文中的重复求解，不能当成 198 款独立啤酒。

验收：从保存的 z、a、c 和原始字段独立复算完整代理差、化学约束和可行性；证书对应新问题。对高残差或活跃约束样本补数值核查，不以旧证书摘要代替新求解。

### 2.2 原始 NA、填补值、floor 编码和实测值分别记录

beer119、beer28 的源双乙酰为空。旧流程填补后将其标为实测，分位数锚定交付策略的 18 条相关记录因此误标为 `verified`。

修改要求：

- floor 作为存储编码及质量点单独处理；将其按某规则转成物理零时必须保留假设标签，不能把所有 floor 当成精确实测零。
- 输出“可核验”“条件成立”“不可识别”“数学约束失败”各自的分子、分母和样本清单。先判数据是否可识别，再报告相应数值检查。

验收：两个缺失源的对应记录不再显示实测已验证；任何填补/floor 假设均能追溯。不能仅把总通过率改成一个更好看的数。

### 2.3 边际分布使用未填补数据，统一四个入口

位置：`src/q3_fix.py:259–264,740–752`，`src/q3_lib.py:493–522`；迁移入口另见 `src/q3_transfer_fix.py:188,620–622`。

当前先填补再拟合经验边际，填补值会被当作真实观测。应同时保留两份矩阵：

- 未填补矩阵及状态 mask：用于经验边际、有效观测计数和缺失审计。
- 训练内填补矩阵：用于确有需要的相关结构、PCA 和感官代理计算。

修改生成外层、生成内层、迁移目标边际、迁移源边际四个入口。公共 `StyleMarginals` 按风格、按列计算有效计数，声明连续部分与 floor 质量点各自的分母，收缩权重不能一律使用风格总行数。某列有效值不足时，采用预先写明的训练集 pooled fallback，并输出状态；禁止从验证集补分布。

验收：用含 NA 的小例确认填补值没有进入经验样本；逐列计数与 mask 一致；全部拟合只读对应训练行。共享类和输入语义变化会改变迁移锚点，必须在修改后重跑迁移。

### 2.4 生成器内层选参统一使用 V 口径

位置：`src/q3_fix.py:778` 仍调用 `src/q3_lib.py:667–672` 的旧 `sqrt(max(U,0)/dref)`；外层已使用 V。

修改要求：

- 内外层复用同一套明确的 V 定义、训练集归一化尺度、可估计格规则和汇总权重。

## 3. 第二问：修方向稳定性，保留真实的不稳定结果

位置：`src/q2_fix.py:703,764–780`。

当前 `sign_stability` 实际是 `P(总体 Spearman 相关>0)`。建议统一以同一“总体 Spearman 点估计”的方向为参照，另存正、负、零/近零及不可计算次数；数值容差和有效分母预先固定。

```text
point_direction = 点估计总体 Spearman 的方向
p_positive = 正方向次数 / 有效次数
p_negative = 负方向次数 / 有效次数
sign_stability = 与 point_direction 同方向次数 / 有效次数
```

点估计为零或不可计算时，标为方向不确定，不自动归为负向。`1-p_positive` 包含零方向，未经确认不能当作负方向频率。这里描述的是总体相关方向，不能改称低秩模型系数的稳定方向或因果方向。

整仓的 `experiments/EXP-0075/outputs.json` 已内联新版 Top-3：主共识 150 条中，36 条负方向的旧 `sign_stability`（实际 p_positive）均在 0–0.022，其中 27 条为 0。这确认了当前标签规则的方向问题；但仍缺零号次数，不能直接把全部 36 条改成稳定。

最省重跑的处理方式：先找同一实验、同一种子的完整符号记录或计数。如果能够准确重建，直接更新派生字段与状态标签。**仅有 Top-3 bootstrap 成员 CSV 不够，因为该文件没有保存相关系数符号。** 也不能用顶层旧 `bootstrap_pi.csv` 替代 EXP-0075 的新实验记录。

若记录不足，固定原 200 行训练集、原风格分层抽样与三组种子（20261025/20261026/20261027），各 500 次，只重算训练内填补和总体 Spearman 的正/负/零/无效次数。先按旧口径核对正方向比例能否复现，再更新新字段与标签；这一步不需要重复图、低秩模型和 Top-3 的全部拟合。保留现有入选频率 π 和 π 优先排序，因为符号字段没有参与该排序。

验收：稳定正相关和稳定负相关的小例均应接近 1；正负交替应降低；零和不可计算情况有明确状态。各次 bootstrap 次数、种子与当前实验一致。

现有最终严格共识 150 条中，95 条入选频率低于 0.5。修正符号并不会自动解决入选不稳定：逐项报告频率和方向，低稳定项给替代候选与谨慎解释。不得把 150 条统一包装成“稳定关键化合物”，也不得把 36 条负方向直接当成 36 条已证实误标。

## 4. 第一问：保留有效结果，纠正模型描述

本轮独立复算的主结果：750 行折外预测，覆盖 250 款酒、3 次重复；A/F30 MAE 为 **0.3592915659**，中位数基线为 **0.3981773284**。这是附件标签尺度上的预测误差，不是 0–6 原始人工等级误差。

必须改：

- 论文中“目标除以训练标准差”改为代码实际采用的“在所给标签尺度上中心化”。低秩模型的目标尺度会改变解；建议按现有正确代码和结果写，避免为了迁就错误公式改变实现。
- 固定主 A/F30 与扩展 50 项的维度字典；0–6 明确为训练分布内相对推断等级。缺少标签的卡面项目列入映射说明，不能凭空造真值。
- 导出完整评分矩阵、连续预测、样本键与维度映射；区分用于评价的 OOF 预测和最终拟合后给出的展示评分。
- 图低秩相对普通 Ridge 的整体改善，不等于已经隔离出“加图”的收益。首选收缩归因表述；只有确需保留图增益主张时，才补同协议的无图低秩消融。

本轮没有必要扩大 Q1 模型家族或为改文字重训。最终干净环境复现属于交付核验；若输入、切分或共享预处理被实际修改，则按依赖重新计算相关结果。
