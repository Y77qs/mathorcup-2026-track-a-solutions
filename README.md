## 3. 三篇论文的关系

- **v1（10-23）**：第一套完整解。论文 47 页、113 个占位符全部由台账渲染、11 条 claim；方法学主线是区分“已计划 / 真实执行 / 验证通过 / 被选中”。
- **v2（10-24 10:48）**：**独立论文**，不是第三套同题解。它基于 v1 的独立副本（台账 rev 780/781）与存量预测做逐维复算，
  重写了一份 5 页审计稿并重新打包；作者自述“DRAFT，不能作为通过质量验收的竞赛终稿”。它与 v1 共享同一条证据链，但作为独立成篇的审计文档归档。
- **v3（10-24 11:24 起）**：第二套完整解。另起炉灶，12 页投稿体；数据取证单独成章，协议更严格，但仍因 `contest.yaml` 在 init 后修改导致的 sha 冲突而无法 `final=true`。

三者的局限与未完成项都在各自文档中逐条列出，未作修饰。
