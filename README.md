# 2026 MathorCup 大数据挑战赛 · 赛道 A 初赛 —— 两套完整解（v1 / v2）

本仓库把**同一道赛题**（2026 年 MathorCup 大数据挑战赛 赛道 A 初赛：商用啤酒化合物 / 感官数据建模）的
**两套完整解题论文与相关代码**，按时间先后整理为 `v1`、`v2` 两个互相独立、自包含的目录。
每个版本都保留原始台账（ledger）、实验元数据与交付包，便于追溯论文中每个数字的来源。

- 归档时间：2026-10-24（源工作区快照）
- 题面：`2026年MathorCup大数据挑战赛-赛道A初赛.pdf`（v1/v2 的 `problem/` 下均有）
- 赛题三问：Q1 用化合物数据预测 50 维感官评分；Q2 识别每个感官维度的 Top-3 关键化合物；Q3 风格条件生成与跨风格迁移

> **状态声明**：两套论文都是 **DRAFT**。项目台账 `final=false`，未冻结、未提交任何竞赛平台；
> 各自 `docs/` 中保留了当时如实写下的未完成项与缺陷披露（`STATUS.md`、`DELIVERY-NOTES.md`）。
> 本仓库是**归档**，不是官方提交物。

## 3. 为什么是两套解

两套是**彼此独立**的解题产线，不是同一篇的两个版本：

- **v1（10-23）**：先完成的一套，论文 47 页、113 个占位符全部由台账渲染、11 条 claim；方法学主线是区分“已计划 / 真实执行 / 验证通过 / 被选中”。
- **v2（10-24）**：在 v1 之后重做的一套，12 页投稿体；数据取证单独成章，协议更严格，但仍因 `contest.yaml` 在 init 后修改导致的 sha 冲突而无法 `final=true`。

两套的局限与未完成项都在各自 `docs/` 中逐条列出，未作修饰。

## 4. 复现

两个版本都是自包含的：`paper/`（md/tex/pdf + 构建脚本）、`src/`（建模代码）、`data/`（清洗后数据 + 划分 + 原始附件）、
`experiments/`（实验元数据）、`figures/`、`ledger.json`（台账）、`contest.yaml`（协议配置）。

- v1：见 [`v1/REPRODUCE.md`](v1/REPRODUCE.md)
- v2：见 [`v2/docs/DELIVERY-NOTES.md`](v2/docs/DELIVERY-NOTES.md) 第 5 节「复现入口」
- 依赖：Python 3.12 + numpy / pandas / scipy / scikit-learn / matplotlib / openpyxl；论文另需 pandoc + XeLaTeX（ctexart）

> 原机器的绝对路径（`/Users/...`）仍出现在部分复现文档中，请按本仓库布局替换为相对路径。
