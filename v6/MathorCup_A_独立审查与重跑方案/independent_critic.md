# A 题拟议改进路线：独立批评与修订

审查日期：2026-10-25。范围：读取题意简报及 v5 源码，独立检查拟议数学模型与科学解释边界；只运行一个 17×6 输入、4 输出的合成矩阵代数检查，未训练赛题模型、未大规模重跑实验。本文是一名独立批评者的意见，不能替代五视角建模共识。

依据：`work/mathorcup-analysis/A/problem_brief.md`；源码根目录 `work/v5-review/source/mathorcup-2026-track-a-solutions-main/v5/src/`。下文源码行号针对本次保留的 v5 快照。

## 1. 总体裁决

推荐优先实施确定性修复，保留图低秩回归与小样本收缩 Copula 作为可检验候选。拟议 Q1 闭式解在明确条件下正确；拟议 Q3 凸 QP 比现有“目标内投影＋不匹配梯度”的实现更容易给出求解证书。但“求解更可靠”不推出“预测更准确”或“化学上可实现”。必须同时修订源点可行性、混合尺度与 floor、派生列、优化自证和模式坍缩的验证。

不建议把新模型的复杂性当成主要创新点。较有价值的改进是：三个问题使用一致的数据契约；优化问题能求解到可检查的解；把已有指标能证明和不能证明的内容说明白。

## 2. Q1：闭式低秩解成立，需满足四个条件

拟议目标为

\[
\min_{B,b:\operatorname{rank}(B)\le r}\frac1n\|Y-XB-\mathbf 1b^\top\|_F^2+\lambda\|B\|_F^2+\gamma\operatorname{tr}(B^\top LB).
\]

**条件：** 预处理后的设计矩阵与响应在训练子集中中心化；`L=Lᵀ⪰0`；`λ>0`、`γ≥0`；秩限制与惩罚作用于最终系数 `B`，不是分别惩罚分解因子。v5 `q1_lib.py:198–231` 写明的目标符合最后一条。

令 `Xc=X−x̄`、`Yc=Y−ȳ`，

\[
A=X_c^\top X_c/n+\lambda I+\gamma L,\quad C=X_c^\top Y_c/n.
\]

`A` 正定。目标去掉常数后为 `tr(BᵀAB)−2tr(BᵀC)`，可写成 `||A^(1/2)B−A^(−1/2)C||²_F`。由截断 SVD 的最佳低秩逼近，若 `Vr` 为 `CᵀA^(−1)C` 最大 r 个特征值的特征向量，则

\[
B^*=A^{-1}CV_rV_r^\top,\quad b^*=\bar y-\bar xB^*.
\]

修订要点：

- 必须在 RankGauss、缺失指示、clip 等预处理之后再计算训练设计均值，不能假设“已标准化就必然严格均值为零”。当前图 Ridge 固定截距为 `Y.mean()`，低秩模型每轮更新截距，见 `q1_lib.py:181–189, 207–229`；比较模型时统一截距处理。
- 实现使用 Cholesky/线性求解，避免显式求逆。对 `Cᵀ solve(A,C)` 对称化；处理接近零的数值特征值。并列特征值可导致系数不唯一，但最优目标相同。
- `λ=0` 不能沿用以上正定论证；本轮候选网格保持 `λ>0` 即可。若以后支持奇异矩阵，需另写伪逆与可辨识性处理。
- 不可直接对普通图 Ridge 系数 `A^(−1)C` 做欧氏 SVD 截断并称精确解；截断应在 A 加权几何下进行。

已做独立小例验证，记录在 `independent_closed_form_check.json`：特征分解解与 Cholesky 白化 SVD 解的最大系数差 `2.78×10⁻¹⁶`；目标与谱证书差 `4.44×10⁻¹⁶`；普通未加权截断目标 3.25398，高于精确解 3.22854。该检查只验证代数与实现路线，不验证赛题性能。

**建议比较层级：** 中位数 → 普通 Ridge (`γ=0, r=全秩`) → 图 Ridge (`γ>0, r=全秩`) → 普通低秩 (`γ=0, r<全秩`) → 图低秩。使用相同折、相同输入表示、相同截距与损失尺度；HGB 仅作为非线性对照。融合必须在内层独立的 OOF 预测上拟合权重，整条选参/融合流程由外层评估。闭式解降低训练目标不保证 MAE 降低，尤其平方损失与 MAE 选模准则不同。

## 3. Q2：两层证据合理，仍要限定“组内”的含义

v5 的风格调整指标是“对全体样本的秩做风格截距残差化，再求 Pearson”，见 `q2_lib.py:88–119`。它可叫“风格截距调整后的秩相关”，**不等于每种风格内部 Spearman 的简单均值，也不排除风格相关斜率、非线性差异或残余混杂**。仅比较绝对相关大小不能识别方向反转。

建议主表并列报告：总相关、调整后有符号相关、单分子候选资格、Top-3 入选频率；若样本足够，再列不同风格中方向是否一致。极少样本风格不独立估计高维模型，不用一个很不稳定的风格相关决定化学结论。

拟议图 Elastic Net 可作为“增量预测关联”的候选：

\[
\min_{b,a}\|y-Xb-Ha\|_2^2/n+\lambda_1\|b\|_1+\lambda_2\|b\|_2^2+\gamma b^\top Lb,
\]

`H` 为不惩罚的风格效应，或等价地在当前训练子集同时残差化 X、y。`λ2>0` 保持强凸性。它回答的是“给定其他变量和风格后的模型关联”；总相关回答的是总体共变，两者不是同一真值的三次重复测量。不要再次用无解释的等权百分位平均掩盖两类问题的区别，也不要依据测试结果选择最漂亮的一种排名。

### 模块稳定性不能用来遮蔽单化合物不稳定

- 高相关化合物相互替代时，较低单项入选频率并不自动证明完全没信号；可以补充模块被选中的概率。但该概率仍是本数据与算法下的重采样行为，不是“该分子为真实原因”的概率。
- 当前 `|ρ|≥阈值` 图的连通分量可能把许多链式相关节点连成巨块（v5 `module_table` 使用 connected components）。一个巨块的高稳定性几乎没有精细化学解释价值。先报告模块大小与边密度，必要时用明确的局部划分方法，并做阈值敏感性分析。
- 若 bootstrap 每次重构图/模块，模块 ID 不可直接相加。可固定训练参考模块计算“该参考集合至少一项入选”的频率，明确条件是模块固定；或重构模块后通过成员重叠匹配，并另报共聚类稳定性。不要混淆这两种估计。
- Top-3 是题面交付，不能靠“一个模块算一个因素”替代。可以同列附同模块候选，诚实标注低稳定项。也不能为了看起来多样而默认强制三项来自三个模块；是否加多样性约束须另做消融。
- `Protein` 是混合物/总量指标，`Iron` 是元素/总量分析指标，不能不作区分地称为明确单一分子。主候选集需要人工核对类型；有效的理化/元素因素可放辅助解释列，不应直接丢弃其统计信息。
- `6.csv` 与原始样本同源，修正名称对齐后只能作附件一致性检查，不能叫外部独立验证。

## 4. Q3：凸 QP 可以成立，但“所有物理边界”这个说法过强

当前 `q3_lib.py:161–179` 对不同尺度列转换不同；仅 70 列有可校验原量纲，其余列不应假设为直接浓度。现有 `low_defect_samples` (`1139–1159`) 在 chemical cap 后沿代理方向平移，确实没有全列 box 约束。一次把 box 与代理线性约束联合求解，可以修复这类算法漏洞。

建议使用训练集拟合的仿射标准化存储坐标 `z=(x−μ)/s`，冻结正尺度；`x` 仍是数据存储尺度，不统称浓度。已验证线性浓度设置非负边界，已验证 log10 浓度通过单调变换转换上界；未知尺度列仅设置“经验支持范围”。训练 min/max 或分位数只是经验范围，不是自然界物理定律。

迁移候选可写为

\[
\min_z (P(z-\mu_t))^\top W(P(z-\mu_t))
+\lambda\|z-z_s\|_2^2+\eta\|D(z-z_s)\|_1,
\]

其中 `W⪰0`、`λ>0`、`η≥0`、`D` 固定。用辅助变量 `u≥±D(z−zs)` 后是凸 QP；已知浓度不增可在 log/线性坐标转成线性上界，线性 stale 代理约束也是半空间。不要在 QP 内加入非线性实际浓度变化 L1 后仍称 QP。`D=I` 时 L1 表示标准化存储坐标的改变量，不是 mg/L 配方成本；所有单位与表述须对应。

### 4.1 源点可行性必须先解决

使用仅训练样本的 min/max box 时，一个真实新源样本可能在 box 外。如果源浓度低于训练下界，同时要求浓度不增，则约束可能无解。把源点 clip 到训练范围再比较“不恶化”会改变比较对象，属于错误修复。

可采用两类明确政策：

1. 对经验边界逐源扩张为包含其观测特征值的最小区间，仍保留可信的物理硬边界；这是利用推理时可见 X，不等于引入其 Y。输出标记源点是否处于训练分布之外。源点保证对 `c_new≤c_source` 与 `f(z_new)≤f(z_source)` 可行。
2. 维持训练支持域，但允许报告“此源样本在当前约束下无可行迁移”；保留原样作为保守交付，不能伪造成功。

若规定“绝对不增”，不要再额外加入严格下降的小 margin 导致源点本身不可行。浮点容差作为检查容差单列，不能改成可见的物理恶化额度。若有真实源点违反可信物理边界，先作为数据问题处理，不能用优化自动纠正并隐藏。

### 4.2 floor、原始缺失与已测零不能混为同一状态

现实现把所有检测到的 floor code 解释为物理零；仅凭重复低值不能证明这一点。凸投影还可能把 floor 状态连续挪动到“略高于 floor”的值，造成新的人造伪精度。

建议在数据契约逐列/逐样本保留 `observed_positive / measured_zero / original_missing / encoded_floor_unknown` 状态。可先抽取离散编码状态，再在固定状态下优化连续部分；状态若需切换，需另定义模型，不能偷偷当连续数移动。对未知 floor 源可冻结该存储值并报“未知状态保持”，但不能标记“真实浓度不增已验证”。对缺失的源浓度，仅冻结填充值也不能证明真实不恶化。四化学约束在有可验证浓度的格子上逐项判定，其余输出 `unknown`，不要把它们计为 pass。

### 4.3 一般风格生成与低缺陷设计需要不同评估

原始风格条件生成器要复现观测风格分布。投影后的低缺陷样本来自另一个分布，并会在约束边界堆积、改变相关和多样性。把所有自然风格生成都强制低缺陷，再用它们声称忠实复现原始风格，是不一致的目标。

保留三个明确产物：原始条件生成；经约束的低缺陷设计；逐源迁移。分别报告 projection 比例、标准化移动量、每种约束激活率、边界堆积率、协方差/分位数变化和真实数据相似性。生成投影可用 `min ||z−z_raw||²` 的 QP；求解无解时必须拒绝该抽样或给出状态，不能循环 clip 后视为有效。

## 5. Q3 的三个科学风险不会因“凸”而消失

### 5.1 均值坍缩与目标距离自证

以目标风格均值的 Mahalanobis 距离为目标，本来就奖励趋向中心。平方距离降到接近零只说明优化达成了自己设定的指标；所有源都接近同一均值也能非常好。PCA 低维距离还看不到被丢弃方向上的异常。

- 基础方案保留目标均值 QP，但必须增加全维距离、到目标真实样本邻域的距离、输出两两距离/协方差、源差异保留率，并与“目标均值投影”这个故意会坍缩的基线比较。
- 可把每个源的目标参照改为事先固定的分位数映射目标 `a_i` 或随机目标锚点，优化 `||z−a_i||²` 加源改变量与约束，仍保持逐样本凸。锚点用训练目标数据确定，不能后验挑选评估最好的一份。其合理性仍需完整联合分布检查，逐维分位映射并不保证联合分布正确。
- 用目标 28 例训练 PCA 再在同 28 例上评估 target distance，仅可作设计描述。严格的测试应使用未参与目标几何、选参、代理拟合的目标观测，并承认其样本量很小。

### 5.2 代理优化不能证明真实感官风险降低

stale 线性代理的约束只保证该拟合函数预测不增，优化会主动寻找它的薄弱方向；当前代理泛化 R² 较低更应控制结论强度。源改变量、经验支持域与稀疏改动可减少过分外推，但不能消除模型误差。

建议：训练/优化使用主代理；用未参与设计的交叉拟合预测、不同形式的辅助模型、bootstrap 重拟合代理检查变化符号一致性；同时报告主代理 OOF 性能。此类交叉模型一致性仍不是实酿干预验证。若多个 bootstrap 线性代理都要求 `f_b(z)−f_b(zs)≤0`，约束仍凸、源点仍可行，可作为保守敏感性方案；不能称其为经过校准的真实风险概率保证。

`trans-2-nonenal` 有明确化学测量列时，应直接约束该列，而不是仅约束 t2n 感官代理。缺失其阈值时选“测量浓度绝对不增”足以形成清楚的自定保守政策；不能声称补齐了官方阈值。

### 5.3 派生列可能让成分向量自相矛盾

231 列包含总量/汇总项，如 `GFS`、`esters_sum`、`aroma_hops_sum`、`acids_sum`、`sulfur_sum`，`target_columns.py` 与 `q2_chem_meta.json` 已标注一部分类型。独立生成或独立优化所有列，可能造成总量与组成项不一致。

- 仅当原始定义、成员、单位、变换和系数已核实且在原数据上复算通过时，才施加确定性汇总关系；优先仅优化基础量，最后重新计算已知派生量。
- 混合 log 尺度下，真实浓度的加和一般在 z 上不是线性等式；强加此类约束后不能继续宣称整个问题是 QP。可把已核实派生特征从优化和代理的自由变量中删除，由基础量输出后重算，并重新拟合仅用基础量的代理；或明确使用非线性求解器并重新验证。
- 如果来源定义不明，仅凭 `sum` 名称不能猜成员。将其列为未验证关系，不能凭直觉补配方公式。报告“统计特征谱”而不是完整可酿造成分方案。

## 6. 未见风格只能检验退化行为，不能声称学会新风格

`StyleMarginals._marginals` 与 `GaussianCopula` 对训练未见风格退回 pooled 分布。仅有类别标签、没有目标风格样本或风格描述变量，模型没有信息识别那个新风格；相同回退分布不会自动变成该风格的合理谱。

主评估应是“已见风格的新样本”分层外层验证，稀有风格单列误差和区间。整风格留出可作为分布外压力测试/回退行为检查；除非增加独立可用的风格属性与相应条件模型，不叫零样本条件生成成功。不能用被留出风格的任何数据选参数再称全流程未见。

## 7. 建议纳入插件重跑清单的停机条件

1. 先跑契约：名称键一一对齐；缺失/未知状态显式；逐列尺度/单位可追踪；训练/评估 beer 无交叉。
2. Q1 用小例谱证书与白化 SVD 交叉检查，完整秩退化为图 Ridge，`γ=0` 退化为普通惩罚低秩；统一截距；新模型不得在测试分数出现后继续无记录挑选。
3. Q2 每个 bootstrap 从正确训练样本重做预处理和评分；固定候选类型、输出有符号信息；最终按 π 排序的集合与 Jaccard 的集合完全一致；π 不标因果概率；模块匹配规则落盘。
4. Q3 每个投影/迁移保存求解状态、目标值、所有约束最大残差、下界/上界残差、QP KKT 残差或求解器 gap；失败状态不得导出为成功样本。抽样用另一个独立实现复算物理与代理约束。
5. 构造必要边界小例：源在训练 box 外；源已在阈值上/下；源有 floor 或原始缺失；proxy 权重近零；约束无解；源保持不动；只约束四个化学列不能改变其他列成为负浓度。
6. 生成自然分布和低缺陷投影分别统计；迁移必须对照“不动源”“目标均值投影”“分位映射再投影”。若只胜过不动源的自定义目标函数，而在独立风格保持/多样性上失败，不升级为最终模型。
7. 分布距离固定公式与标准化；小样本的无偏 U 估计可以为负，不得剪成 0 再宣称完全一致。若以非负经验 V 距离为主则明确有限样本偏差并统一对照样本量；稀有风格不伪造可靠区间。
8. 实验前固定比较规则，先小网格、共同随机数和相同折；没有提升则保留简单模型。修复现有错误本身是必须完成的工作，不以跑出更高指标为前提。

本轮没有认定任何新方案已优于 v5.1；建议先实现并验收上述确定性修复，再启动有限候选比较。
