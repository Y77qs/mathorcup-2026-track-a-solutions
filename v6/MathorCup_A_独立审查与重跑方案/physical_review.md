# A 题第三问：独立物理机理与数据语义审查

审查日期：2026-10-25。范围：对“保留收缩 Copula，统一 QP 投影，使用源点修改代价和目标参考样本”的提案作可实施性审查。直接读取 `problem_brief.md`、原始题面提取文本、`v5/src/q3_lib.py`、`target_columns.py`、原始 `1.csv`、`8.xlsx` 以及 v5.1 生成 CSV；未把旧报告作为本轮新证据，未训练、调参或生成新结果。确定性复核脚本及结果为同目录 `physical_review_check.py`、`physical_review_evidence.json`。

## 审查结论

保留收缩 Copula、将所有已声明的连续约束同时放入一次 QP，比现行依次移动两个感官代理的做法更可靠。但它只保证**已写入模型的约束**，不能称为“完整物理可行性”。有三个必须在方案中补齐的边界：五个派生汇总指标的计算关系未提供；零、低值编码和原始缺失不能统一当真实浓度零；感官代理下降不证明真实缺陷下降。

建议先实现可审计的 226 个非派生变量生成与约束；五个派生列作为单独的重建层或带不确定性的补充输出。若保留现有 231 列联合生成以便最小修改，必须明确“聚合恒等式未验证”，且禁止优化器只调整这五列来改善感官预测。

## 2. 硬约束要先建立字段契约

每列至少登记 `name / storage_transform / physical_unit / calibration_evidence / derived / observed_status / bounds_source`。每个源值登记 measured-positive、calibrated-record-zero、coded-floor、missing、previously-imputed 等状态。`8.xlsx` 提供的原值也应保留来源；其中的 0 是“附件记录的 0”，没有测量协议时不能自动升级为“已证明精确零浓度”。

对 33 个线性校准浓度列，物理非负就是存储值非负。对 37 个 log10 校准列，负存储值完全可能合法，正值还原使用 `10**x`。这 37 列还包含 pH、酒精度等理化指标，统一称作“浓度”也不准确。对 161 个未校准列只能在当前存储尺度讨论经验分布；`physical_conc` 中直接原样返回不能提供物理单位保证。

QP 使用训练集拟合的坐标 `z_j=(x_j−μ_j)/s_j`、`s_j>0`。线性浓度约束 `x_j≥0` 可写为 `z_j≥−μ_j/s_j`；正的物理上界 `c_j≤u_j` 对 log 列变成 `z_j≤(log10(u_j)−μ_j)/s_j`，仍是线性约束。零不能用 `log10(max(0,1e−300))` 伪装成精确零；需在进入连续 QP 前固定零/编码分支，或声明该约束不可证。

训练最小值、最大值或稳健分位数形成的是**经验支持域**，不是化学定律。可以作为限制外推的统计约束，但要记录来源和越界处理。在非增加上界小于训练最小值时，不得把上界偷偷截到训练最小值并宣称满足：可保留合法源点、按预声明规则放宽经验下界，或报告不可行；不能放宽真实非负和缺陷约束。

## 3. 五个派生列的可实现处理

原题说明派生关系存在，现有附件不足以给出精确计算式。`acids_sum`、`esters_sum`、`sulfur_sum` 甚至存在负存储值，因此直接相加已校准的正浓度无法解释当前存储值。应按以下顺序处理：

1. 查找原始计算说明与单位转换表；只有公式和参与成员得到核实后，才能把五项从生成自由变量中移除，再从生成的基础变量确定性重算。
2. 当前可实施候选：226 个非派生列作为生成与迁移变量。用训练折的 226 列拟合五个汇总字段的重建模型，独立折评估误差，并输出重建区间。它是统计补全，不是守恒定律；不得据此宣称“聚合一致性已严格满足”。缺失的 `aroma_hops_sum` 不作为真实目标参与误差统计。
3. 若重建误差不可靠，则保留该字段缺少一致性证据的标记。可继续交付其他可验证谱；不能填入猜测公式。若比赛输出必须给齐 231 列，可附上统计预测值和状态列，讲清它与已校准部分的证据等级不同。
4. 为保持 QP 简洁，优化用的感官代理改为仅依赖 226 列；另用含五汇总列的既有 Q1 模型作事后敏感性对照。若发现可靠的仿射重建式，可代入代理保持 QP；若采用非线性重建，则不能继续称整个目标和约束都是精确 QP。

不建议一边把五汇总字段作为独立优化变量，一边允许优化器通过改变“总酯”而几乎不改变任何酯类成分来改善感官评分。冻结五列也不解决成分变化后的汇总一致性，只能作为明确标注的诊断消融。

## 4. 缺陷的三层声明与不可证状态

**测量域化学约束。** DMS、Diacetyl、4VG 使用附件均值阈值作主分析、中位数阈值作敏感性分析；阈值是来源条件下的参考值。对于源值确实可用的列，若定义“超阈程度不增加”，可用 `c_new≤max(c_source,T)`；若定义更严格的“浓度不增加”，用 `c_new≤c_source`。两者均可检验，但不能混用名称。无阈值的 E-2-nonenal 单独要求 `c_new≤c_source`；本次 11 个源正测量齐全，因此应加入这一硬约束。

**观测状态不足。** 原始源值缺失而经过中位数插补时，`c_new≤插补值` 只能称作“给定插补情景下满足”，不能声称对真实源值满足。beer=119、28 的 Diacetyl 可使用附件校准零作一个显式情景；更稳妥的主表同时显示 `stored=NA / calibrated_record=0 / interpretation=unresolved`，证书状态记为“依赖零记录解释”。4VG 的 9 个零源采取“保持原编码/零记录类别”是可执行的操作，但证明的是编码不增加，仍不等于已证真实微量浓度不增加。只有确证的区间 `[L,U]` 才能做区间鲁棒非增加；对于对所有源真值都成立的非增加，需要新值上界不大于源下界 `L`。把未知源的上界 `U` 当上界约束只能证明更弱条件。

**感官代理约束。** `t2n` 感官标签和 `X.E..2.nonenal` 化学列不同；`stale_hops` 只有感官项。可以约束代理预测差 `βᵀ(z_new−z_source)≤0`，并用独立折误差和重采样敏感性说明不确定性。若使用多组 bootstrap 系数同时约束，仍是若干线性不等式，可保留 QP；但它只对这些拟合模型稳健，不是实际品评保证。模型优化会利用代理弱点，代理分数不能同时充当设计目标和唯一验收标准。

每个约束的结果至少分为 `verified_on_recorded_scale`、`conditional_on_assumption`、`proxy_only`、`unverifiable`、`violated`。这些是本队证据分类，不是竞赛官方评定。

## 5. 保留收缩 Copula 的理由与边界

收缩边际 `F_js=ω_js F_emp,js+(1−ω_js)F_pool,j` 与风格相关矩阵向共享结构收缩适合本题的小样本。对缺失列，建议 `ω_js` 使用该列该风格的有效观测数；不要把中位数插补当新增真实观测。零/代码的经验点质量可以保留，但叫“观测编码的点质量”，不称已核实检出限概率。相关矩阵估计仍需预先声明缺失处理与正定修复；所有步骤只能在训练折中拟合。

目标风格有 3 个样本时，高度依赖全局结构是诚实的证据边界。生成一万条谱不会增加这 3 个真实样本所包含的风格信息。评价既给逐风格结果，也给有效样本数、收缩权重和区间，不能只报样本加权平均掩盖稀有风格。

现代码 `StyleMarginals._marginals/forward/inverse` 和 `GaussianCopula.uniforms_from_normal` 对未见风格回退全局模型。因此在没有风格描述符或目标风格样本的条件下，它生成的是共享分布，不能辨认这个新名字所代表的特定风格。所谓未见风格实验只能报告“缺少风格信息时的池化回退”或预声明的压力测试；不能证明零样本条件生成。若使用少量目标风格样本校准，则改称 few-shot/少样本并单独划分拟合和评价样本。

## 6. 统一 QP 和保持个体差异的迁移

对一条 Copula 候选 `z_raw`，在预先固定编码状态后求

`min_z  1/2 (z−z_raw)' W (z−z_raw)`，其中 `W` 正定，约束包括所有已核实下/上界、化学缺陷上界及选定感官代理线性不等式。

这把约束同时求解，避免后一个代理移动破坏前一个代理或非负域。若不可行，返回不可行记录或重新生成候选；不可静默返回违约样本。对所有样本记录投影距离、是否卡在边界、约束活动集合；约束后分布可能与原始 Copula 不同，必须重新评价。

迁移为每个源 `z_s` 配置独立目标参考 `r_i`，来自训练折目标分布或预先指定的目标参考匹配。可用

`min_(z,t) 1/2 (z−r_i)'H(z−r_i) + λ Σ_j w_j t_j + ε/2 ||z−z_s||²`

满足 `t_j≥z_j−z_s,j`、`t_j≥−(z_j−z_s,j)`、`t≥0`，以及该源的共同可行域。`H` 半正定、`ε>0`；这是真正的凸 QP，L1 修改成本作用于源点而不是初始化点。标准化存储尺度的 L1 只是数据尺度的修改代价，不能称为添加原料质量或真实酿造成本。缺失/零分支在求解前确定并另记。

参考样本而非统一中心给迁移保留差异的机会；它不自动保证多样性，因为多个参考仍可能投影到同一边界。需记录目标参考 ID/随机种子，并检查迁移样本之间的距离、方差、重复率、目标覆盖度及源点身份差异。限制二次距离在过少 PCA 方向时还需检查正交方向外推，不能只用小的 PCA 距离证明整体谱接近目标风格。

## 7. 插件重跑必须产出的验收证据

以下是建议的项目验收规则，非官方比赛阈值：

- **字段契约和单位检查先通过。** 已校准浓度、理化指标、未校准存储值、派生字段分别登记；37 log 列能负存储、33 linear 浓度不得负；保留缺失和零记录来源。
- **修复后的每一条谱逐项检查。** 对 QP 输入、输出及 CSV 回读输出都检查物理尺度与标准化尺度约束残差；公差按各列单位/尺度预声明，禁止一个大绝对公差掩盖极低浓度的恶化。报告最坏残差、失败数和求解状态，失败样本不计入成功率分母而不披露是不允许的。
- **源约束明细覆盖全部 11 行。** 每项列源值、新值、单位、阈值、解释口径及证书状态；两个 Diacetyl 缺失源和 9 个 4VG 零编码源单列；E-2-nonenal 浓度非增加作为新增硬门槛。
- **QP 可行性和最优性可复核。** 保留可行性残差、KKT 残差和目标值；简单低维例用解析/枚举或第二求解器交叉验证。刻意构造冲突约束时必须返回不可行，不能只截断出一个看似有效结果。
- **聚合问题不能隐去。** 若获得确证公式，检查重算残差；若仅统计重建，报告 OOF 重建误差/区间；若未知，输出“不具备恒等式证书”。
- **模型与感官评价分开。** 在同一独立测试协议下比较投影前后分布、各风格覆盖、多样性及近邻复制风险；给生成前后代理值但不拿其优化下降当真实感官验证。保留原谱及最小修改基线。
- **小样本与未见风格清楚标记。** 按风格报告 n、有效观测数、收缩权重；n=0 且无描述符时不得输出特定新风格学习成功结论。

完成这些检查，可以把结果称为“满足已声明数据与代理约束的候选化学谱”。由于缺少原料投料、发酵过程、化学反应约束和实酿/感官实验，仍不能把它称作已验证可生产的酿造配方。
