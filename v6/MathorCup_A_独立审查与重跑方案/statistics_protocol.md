## 三、统一切分：外层3折×3次，内层3折

预登记3个外层重复种子，例如 `[20261025, 20261026, 20261027]`，只是计算种子，不代表未来日期。对每个风格内部打乱，轮转分给3折，再用仅依赖风格计数的确定性规则平衡总折大小。保存完整 `beer → repeat → fold` 表及哈希。主Q1模型仍不输入风格；风格只用于切分、分组报告与Q2诊断。

全250行每次重复各测试一次，得到每款啤酒每模型3个外层预测。Faro最少3行，外层每个测试折1行、外层训练2行。对这2行做内层3折时，把它们放入两个不同的验证折，第三验证折无Faro；于是每个内层训练仍有1或2行Faro。**不复制稀有样本，不把外层测试行塞回训练，也不为了使用标准分层API而静默改风格名。** 可用自定义风格内轮转分折；“每个验证折都含每一种风格”在内层不可能，应写明。

Q1是跨风格汇总模型，内层某风格仅1个训练样本仍可拟合。任何按风格估计方差/相关的附加模块，在该风格有效样本≤1时必须退回合并样本估计，不能把零方差或单位相关当作该风格证据。Q2的风格去均值在单例组给出零残差，这一行没有风格内协变信息；不能为保留它而捏造组内扰动。

每个外层训练集独立生成自己的内层切分。外层测试标签只在全部拟合、权重、映射冻结后用于打分。全数据最终模型另做一次相同的3折内部选择，然后用全250行拟合；它的拟合值不能再计入外层分数。

## 四、Q1：精确图低秩 + 真正Ridge + 小规模融合

### 1. 精确解及其必要验证

沿用原目标：

`min_{rank(B)≤r,b} ||Y−ZB−1b'||_F²/n + λ||B||_F² + γ tr(B'LB)`。

先用当前训练集把**全部设计列（含缺失指示）和目标**中心化，得到Zc、Yc。令 `M=Zc'Zc/n+λI+γL`、`C=Zc'Yc/n`，λ>0使M正定。若Cholesky `M=A A'`，计算 `T=A^{-1}C`；对T做SVD并取前r项得T_r，精确解为 `B=A'^{-1}T_r`，截距 `b=Ybar−Zbar B`。这是完成平方后在可逆坐标中取最佳秩r近似；在所声明二次目标下具有全局最优性，数值误差另检。

该替换只保证同一训练目标不比未收敛ALS差，**不保证外层MAE更低**，因为训练优化平方误差、比较指标是MAE，且低秩/正则本身要验证。必须在小型合成矩阵上做：r≥q时等于 `M^{-1}C`；γ=0/r≥q时等于纯Ridge；最优目标随r增加不升；带截距平移等变；原ALS目标不能比精确解更低超过浮点容差；数值残差与PSD检查。

### 2. 一张网格同时覆盖必要对照

建议本轮冻结如下72格，不在看到外层成绩后扩网格：

| 维度 | 值 |
|---|---|
| 特征表示 | clipped-z[-8,8]、Rank-Gauss；保留旧实现以隔离求解器修复，名称必须准确 |
| λ | 0.1、1、10 |
| γ | 0、0.1、1 |
| r | 3、6、10、50 |

50是目前目标数，r=50为不限制秩。由同一缓存导出独立、可公平比较的预登记流程：中位数；纯Ridge（γ=0,r=50，内选表示/λ）；无图低秩（γ=0，内选表示/λ/r∈{3,6,10}）；允许图的降秩/满秩模型（内选全72格）；最后一个可选融合流程。r=50的图模型与纯Ridge应分别命名。

对一个训练块，每个(表示,λ,γ)只需要一次Cholesky与一次小尺寸SVD，其前缀可同时给出4个r。9个外层训练×3个内层验证×2表示×3λ×3γ = **486次因子分解/SVD**，产生1944个秩候选分数；不用做1944次25轮ALS。每个训练块的填补、图与表示也缓存；图可在两个表示之间复用，只要声明图从填补后的原存储尺度Spearman估计。

网格最优落在边界先报告，不自动扩大；若确需扩展，登记为下一轮探索，完整重跑固定协议并说明重复查看。主报告不能只挑第二轮最好结果。

### 3. 融合的正确损失与验证边界

保留固定HGB参数，明确 `early_stopping=False` 与随机种子，逐目标拟合；树超参本轮不搜索。用外层训练内部3折产生中位数、图模型、HGB预测，然后求：

`min_{w_k≥0, Σw_k=1} mean_{i,t∈AF30}|Y_it−Σ_k w_k Yhat^{inner}_itk|`。

这是3个权重的凸问题，可以用带绝对误差辅助变量的线性规划精确求解；更简化时只做图模型与HGB二元混合，可用一维凸分段线性优化。预先固定一种。只给一套全局权重，暂不逐目标给50套，以免增加小样本自由度。无约束平方损失再投影应删除。

要诚实记录：当前训练内部OOF先选图超参，再拿选中的OOF拟合权重，所以该预测矩阵对“整个选超参程序”并非严格未见；更重要的是权重已经用这些标签学习，因此拟合后的内部MAE只能叫 `meta_fit_mae` / `inner_selection_mae`。**即使采用精确MAE最小化，内部融合损失必然不劣于它允许的单模型顶点之一，这本身不能证明融合有效。** 不再以1e-4内部差值宣称稳定改善。

节省算力的可行选择：把“内部选图参数→内部OOF拟合全局权重→在整个外层训练重拟合各基模型”视为一个固定学习算法，每个外层测试只评估它一次。外层标签从未参与这些步骤，因此外层可以评价该自适应算法的效果；无需为了得到可用外层比较而加第三层CV。如果要把内层融合分数本身写成独立效果，才需要更深的交叉拟合/元层验证，本轮不做。

固定HGB需要9×(3内层+1外层重拟合)×50 = 1800个目标拟合；全250最终选择/拟合另需200个。小样本下可缓存并限制线程避免内外并行争抢。HGB的收益若没有越过预登记接受线，最终部署退回选中的线性流程。

### 4. 新结果怎样接受、怎样退回

下列是建议预先冻结的**团队工程裁决线，不是官方评分标准，也不是显著性检验**：

1. 所有契约/求解器等价/泄漏边界测试通过，是硬门槛。
2. 复杂流程相对相应简单流程，平均3次外层重复的MAE_AF30至少降低1%，且3次重复改善方向一致，才作为优先保留候选。
3. A15与F15任一子组，以及MAE_50，不得恶化超过2%；若出现则列为任务权衡，默认退回简单流程，不用更好看的总均值掩盖子组代价。
4. “图有贡献”应比较相同外层/同样调参规则的允许图流程与γ=0流程；“低秩有贡献”比较低秩流程与纯Ridge；“融合有贡献”比较融合流程与其图/线性基流程。不能从一张最终模型结果表推断每个组件都有增益。
5. 若差异小于1%或重复方向相反，报告证据不足，优先简单模型。可以保留复杂结果供讨论，不能继续换种子直到通过。

如果实际交付模型族是读完外层结果再选出的，应报告全部预登记流程，并说明外层结果也参与了这次研究裁决；不要声称所选赢家的分数是完全没有选择乐观性的最终外测成绩。若追求更严格的性能声明，需要新的外部数据或在另一个完整外层再包住“选择模型族”这一步，当前小样本不建议再加层求一个看似精确的数字。

## 五、Q2：先修复与拆解证据，再考虑新稀疏模型

### 1. 最小必要版本

建议首先做Q2-R0：修正附件6名称对齐；保存总体及风格调整相关的**符号**；更正“单体”候选分类；修正点Top3与πTop3的Jaccard标注；把原三项平均命名为“多标准折中分数”；显示三项原始分数与候选边界。这些不需要引入更复杂模型，也应当先于任何新排名竞赛。

Q2是这批样本的描述/解释任务，冻结模型规则后可用全部250样本给最终名单，旧200样本名单保留为历史对照。扩大到250会自然改变名单，不能把改变全说成算法改进。若用Q1预测性能给Q2模型选参，必须标注这是一套以预测误差选择的解释模型，并将固定选参之后的bootstrap称作条件稳定性。

### 2. 网络真正参与、又不混淆统计对象

推荐的新候选Q2-R1是**两条并列轨道，不把两条轨道的分数直接平均**：

- 轨道T（总体多变量预测标记）：当前训练X与Y经预处理，拟合精确图正则模型，主选择分数为同一尺度下的 `|B_jt|`，由其bootstrap Top3频率排序。总体Spearman只作方向/边际强度的伴随证据，不与它声称同一效应。
- 轨道W（风格调整后的多变量标记）：对同一种表示的X与Y先按风格投影去组均值，再用残差拟合相同图正则模型；网络也应从风格调整后的化学残差相关构建。主分数为对应的 `|B_within,jt|`。另列现有partial-Spearman诊断，说明后者是在秩空间而不是原标准化空间中的关系。

若本轮预算只够一条主模型，建议**轨道T提供正式Top3，轨道W作为风格依赖诊断**，因为题目未要求控制风格后的直接效应。选择这一口径时应写“总体预测关联因素”，避免“控制了风格仍独立造成该感官”的表述。也可由团队事先选择轨道W为主，但必须明说改变了要回答的问题。

正则系数不是唯一可识别的化学效应：同一组高度相关化合物可互相替代，图惩罚甚至会主动使其系数接近。采用β是为了定义一个可重现、网络实际参与的排序规则；它仍要靠稳定性、消融和化学证据证明实用性。不能把新规则改名后就宣布比原综合分更准确。

两条轨道的参数须预先冻结或只通过训练内验证确定；不为获得更高π或更高方法Jaccard反复调τ。图阈值主值0.5，0.4/0.6作为明确敏感性；附件2的全量图仍单独提供以覆盖题面“利用附件2”的描述要求。

### 3. π、边稳定性与模块替代的恰当解释

每个候选流程至少500次按风格有放回抽样，各风格保持原样本数；每次重算缺失处理、缩放/秩、图、模型、候选排序。若超参固定于全数据选择结果，报告“条件于本规则和超参的π”，不说包含了全部选模不确定性。想检查全流程变化，可以利用9个外层训练集合的Q2结果作为切分敏感性，或额外100次包含重新选参的bootstrap；不需要把昂贵完整调参塞入每次500重采样。

500次下，单个π的最大Monte Carlo标准误是 `sqrt(.25/500)=0.0224`，大致95%误差尺度约±0.044；这是**把同一数据集bootstrap重复更多次能缩小的模拟误差**，不是化合物效应或因果的置信区间。若第三名与第四名π相差不到0.05，可预登记仅对存在边界争议的输出把总次数追加到2000（使用同一随机流前缀），并同时列候选4–6名；不得把更多模拟当作新增真实样本。

π没有题目规定的统一“通过值”。建议：≥0.8标注较高重复入选；0.5–0.8中等；<0.5明确写“未稳定锁定”。这些只是展示标签，不剔除题目要求的第三名。若每次都是A/B/C轮流被选，第三名π低说明单体不能稳定分辨，不应伪造一个确定答案。

模块应当帮助解释这种替代，而不强行给每个模块分配一个Top3名额。原τ=.5连通分量可能串成很大一组，不能据此说所有节点可互相替代。轻量备选是对 `1−|ρ|` 用complete-linkage，在预先给定的高相关阈值切割，保证组内任意两项均满足所声明相似度；或仅为每个Top3列直接强相关邻居，不引入新的聚类算法。主名单仍是题目要求的单个候选。

模块稳定性应定义为 `π_M,t = P(Top3_t 与 M 相交)`，不能用组内π之和代替概率（和可能>1）。若模块只作注释，可以冻结全样本X得到的描述模块并明确“条件于该分组”；若模块参与模型或选择，bootstrap必须重建并对齐模块，复杂性显著增加，本轮建议先不做。

边频率也只表示该相关阈值在重采样下重复出现。它不证明分子相互作用或因果边。跨方法Jaccard只衡量名单一致性，不能以越高越好替代正确性。

### 4. 新稀疏图模型的优先级

可登记Q2-R2为后备：按目标允许不同稀疏系数的图Elastic-Net，目标含L1稀疏、L2收缩、带符号图二次惩罚。它的优点是直接形成较少候选，目标凸且较容易验证；但它增加至少一个调参轴，对高度相关成分仍会任意替代，不能保证π提高，更不能使因果识别成立。

不要仅采用跨50目标的整行group-lasso后把同一少数变量强塞给全部50维；这与每个感官维度各自Top3的要求可能不匹配。即便试稀疏模型，也应让逐目标系数保留差异。

先做R0和R1的理由：当前最大不确定性首先来自错误对齐、目标口径混合和小样本共线性；更换稀疏优化器不能修复这些概念问题。只有R1仍暴露大量单体替代、而团队确实需要更简洁条件模型时，才运行R2一轮冻结网格。接受R2至少要求：同一验证下预测能力不劣于R1超过2%，主候选稳定性改善不是由强制固定Top3/大量系数同为0造成，图/无图消融有证据，且化学语义审核通过。不满足则保留R1或R0，报告未发现新模型优势。

## 六、区间和显著性：不要把9折当9个独立实验

9个外层折之间共享训练样本；每款啤酒出现3次测试，50个目标也相关。不能用“9个分数的SD/√9”作标准误；不能把750行预测当750款独立啤酒；不能用150或12500个感官单元虚增样本量。3次重复的均值范围也不是95%置信区间。

首轮最稳妥的报告是：3次重复各自的完整250行成绩、配对差、最小/最大变化、逐啤酒及逐风格差异。若需要一条区间，可把每款啤酒在3次重复的配对损失差先平均为 `d_i`，按原风格内重抽**beer**，得到平均d的分位区间，但必须命名为“固定已拟合交叉验证预测下，样本构成敏感性区间”。它只扰动测试样本构成，没有重新训练，不能覆盖全部算法训练不确定性，不能冒充严格外部泛化置信区间，也不用于显著性宣传。

若必须提供更严格的泛化区间，应预先增加能处理交叉验证误差相关的专门方案或获取独立数据；不是简单增加种子再套t检验。对于本轮预算，给透明的重复结果和保守接受线比给一个不可靠的p值更合适。

关于这两个原则的原始方法来源：Varma与Simon研究了用同一CV选择并报告模型造成的偏差，支持把整个选择流程包进外层验证；Bengio与Grandvalet说明一般K折CV误差方差不存在通用无偏估计器，忽略折间相关会低估不确定性。参见 [Varma & Simon, 2006](https://bmcbioinformatics.biomedcentral.com/articles/10.1186/1471-2105-7-91) 与 [Bengio & Grandvalet, 2004](https://jmlr.org/papers/v5/grandvalet04a.html)。这里引用的是统计方法原则，不把原论文的具体模拟结论当作本赛题已经验证的成绩。

## 八、给队员理解用的两个例子

**融合的例子。** 你让两位同学各做一套练习题，然后看答案调成“甲占70%、乙占30%”，这套练习题上更好是合理的，但比例已经参考过答案。真正判断70/30好不好，应交给另一套还没用于调比例的题。内层OOF是调比例的练习卷，外层才是检验这整个调比例方法的卷；原来“OOF”这个名字不会自动使最终融合分数变成未见成绩。

**总体和风格内的例子。** 假设某类啤酒普遍更苦，某成分也普遍更高，把所有风格混在一起看会得到强相关；但在每一种风格内部，这个成分高一点的酒不一定更苦。前者适合作为跨风格的预测标记，后者更接近“同风格里还有多少关系”。把两者平均成一个数字会隐藏差别；并列展示才让队员知道Top3为什么入选、在什么范围内成立。
